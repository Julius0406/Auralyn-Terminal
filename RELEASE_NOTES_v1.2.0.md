# Auralyn Terminal v1.2.0 Stable

- Orbit Global Menu support with dedicated Auralyn menus in the GNOME top panel.
- Actions include settings, new/close tab, copy/paste/select all, Smart Search, system update, zoom, tab navigation, About and Quit.
- Works with Orbit shortcut menu fallback on Wayland; no optional daemon required.
- Install the mapping once with auralyn-orbit-menu-install.
- GitHub publication is intentionally not part of this local build.
